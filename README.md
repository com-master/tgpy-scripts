# tgpy-scripts

## Установка модулей

Скрипты длиннее лимита Telegram (4096 символов), поэтому **не вставляй код
текстом в чат** — TGPy попытается выполнить обрезанный кусок и упадёт.

- **Файлом:** отправь `recap.py` / `quote.py` документом в «Избранное»,
  ответь на него `modules.add()` — имя модуля возьмётся из имени файла.
- **Или на сервере:** скопируй файл в `~/.config/tgpy/modules/`
  (или `$TGPY_DATA/modules/`) и выполни `restart()`.

Модуль сохраняется и загружается при каждом старте TGPy.

## recap.py — рекап чата через нейросеть

Собирает сообщения чата (по количеству или по дате), отправляет их в нейросеть
с инструкцией «Рекап» и присылает результат в этот же чат.

### Установка

1. Открой `recap.py` и заполни настройки вверху:
   - `RECAP_API_KEY` — твой API-ключ;
   - `RECAP_API_URL` — endpoint `/chat/completions` любого OpenAI-совместимого API
     (OpenAI, OpenRouter, DeepSeek, Groq, локальный LM Studio и т.д.);
   - `RECAP_MODEL` — модель.
2. Установи модуль (см. «Установка модулей» ниже).

### Использование (в любом чате)

| Команда              | Что делает                              |
|----------------------|-----------------------------------------|
| `.recap 100`         | последние 100 сообщений                 |
| `.recap 29.09`       | с 29.09 текущего года до сейчас         |
| `.recap 29.09.2026`  | с указанной даты (также `2026-09-29`)   |
| `.recap 29.09 30.09` | диапазон дат, включительно              |
| `.recap вчера`       | со вчерашнего дня (`сегодня` — за день) |
| `.recap 3h` / `2d`   | за последние 3 часа / 2 дня             |

**Комментарий к рекапу.** Всё, что после количества/даты, добавляется к слову
«Рекап» в запросе к нейросети. Есть пресеты (настраиваются в `RECAP_STYLES`):

```
.recap 100 коротко          # коротко / кратко — 3–5 главных пунктов
.recap 29.09 подробно       # подробно / детально — все темы и кто что сказал
.recap 2d тезисы            # только список тезисов
.recap 3h только про деньги и сроки   # любой свой текст
```

Ответ нейросети в Markdown (заголовки, **жирный**, списки, `код`, ссылки)
автоматически переводится в форматирование Telegram.

**Рекап другого чата.** Добавь к команде id, @username или ссылку на чат
(в любом месте), и рекап придёт в чат, где ты ввёл команду (например, в «Избранное»):

```
.recap 100 -1001234567890
.recap 29.09 @chat_username
.recap 2d https://t.me/some_chat
.recap 50 id:123456789     # положительный id (личка/бот) — через id:
```

Команда-сообщение заменится на статус, а сам рекап придёт отдельным сообщением.
Также можно вызвать напрямую: `await recap("50")`.

## quote.py — стикеры-цитаты (как @QuotLyBot)

Делает стикер-цитату из сообщения через публичный API QuotLy
(`bot.lyo.su/quote/generate`) и отправляет его ответом на исходное сообщение.
Установка — см. «Установка модулей» ниже.

Ответь на сообщение командой:

| Команда        | Что делает                                         |
|----------------|----------------------------------------------------|
| `.q`           | стикер из одного сообщения                         |
| `.q 3`         | из этого сообщения и 2 следующих (до 10)           |
| `.q #232323`   | свой цвет фона (hex или название, напр. `black`)   |
| `.q 3 black`   | аргументы можно комбинировать                      |
| `.q bot`       | через самого @QuotLyBot (пересылка), если API лежит |

Сообщение с командой удаляется после отправки (`QUOTE_DELETE_CMD`), при ошибке в нём появится её текст.
Аватарки через API не подгружаются — вместо них буква имени на цветном фоне;
с настоящими аватарками работает режим `.q bot`.
