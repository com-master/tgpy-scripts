# tgpy-scripts

## Установка модулей

Скрипты длиннее лимита Telegram (4096 символов), поэтому **не вставляй код
текстом в чат** — TGPy попытается выполнить обрезанный кусок и упадёт.

- **Файлом:** отправь `recap.py` / `quote.py` документом в «Избранное»,
  ответь на него `modules.add()` — имя модуля возьмётся из имени файла.
- **Или на сервере:** скопируй файл в `~/.config/tgpy/modules/`
  (или `$TGPY_DATA/modules/`) и выполни `restart()`.

Модуль сохраняется и загружается при каждом старте TGPy.

## recap.py — рекап чата через нейросеть

Собирает сообщения чата (по количеству или по дате), отправляет их в нейросеть
с инструкцией «Рекап» и присылает результат в этот же чат.

### Установка

1. Открой `recap.py` и заполни настройки вверху:
   - `RECAP_API_KEY` — твой API-ключ;
   - `RECAP_API_URL` — endpoint `/chat/completions` любого OpenAI-совместимого API
     (OpenAI, OpenRouter, DeepSeek, Groq, локальный LM Studio и т.д.);
   - `RECAP_MODEL` — модель.
2. Установи модуль (см. «Установка модулей» ниже).

### Использование (в любом чате)

| Команда              | Что делает                              |
|----------------------|-----------------------------------------|
| `.recap 100`         | последние 100 сообщений                 |
| `.recap 29.09`       | с 29.09 текущего года до сейчас         |
| `.recap 29.09.2026`  | с указанной даты (также `2026-09-29`)   |
| `.recap 29.09 30.09` | диапазон дат, включительно              |
| `.recap вчера`       | со вчерашнего дня (`сегодня` — за день) |
| `.recap 3h` / `2d`   | за последние 3 часа / 2 дня             |

**Комментарий к рекапу.** Всё, что после количества/даты, добавляется к слову
«Рекап» в запросе к нейросети. Есть пресеты (настраиваются в `RECAP_STYLES`):

```
.recap 100 коротко          # коротко / кратко — 3–5 главных пунктов
.recap 29.09 подробно       # подробно / детально — все темы и кто что сказал
.recap 2d тезисы            # только список тезисов
.recap 3h только про деньги и сроки   # любой свой текст
```

Ответ нейросети в Markdown (заголовки, **жирный**, списки, `код`, ссылки)
автоматически переводится в форматирование Telegram.

**Рекап другого чата.** Добавь к команде id, @username или ссылку на чат
(в любом месте), и рекап придёт в чат, где ты ввёл команду (например, в «Избранное»):

```
.recap 100 -1001234567890
.recap 29.09 @chat_username
.recap 2d https://t.me/some_chat
.recap 50 id:123456789     # положительный id (личка/бот) — через id:
```

Команда-сообщение заменится на статус, а сам рекап придёт отдельным сообщением.
Также можно вызвать напрямую: `await recap("50")`.

## quote.py — стикеры-цитаты (как @QuotLyBot)

Делает стикер-цитату из сообщения через публичный API QuotLy
(`bot.lyo.su/quote/generate`) и отправляет его ответом на исходное сообщение.
Установка — см. «Установка модулей» ниже.

Ответь на сообщение командой:

| Команда        | Что делает                                         |
|----------------|----------------------------------------------------|
| `.q`           | стикер из одного сообщения                         |
| `.q 3`         | из этого сообщения и 2 следующих (до 10)           |
| `.q #232323`   | свой цвет фона (hex или название, напр. `black`)   |
| `.q 3 black`   | аргументы можно комбинировать                      |
| `.q bot`       | через самого @QuotLyBot (пересылка), если API лежит |

Сообщение с командой удаляется после отправки (`QUOTE_DELETE_CMD`), при ошибке в нём появится её текст.
Аватарки через API не подгружаются — вместо них буква имени на цветном фоне;
с настоящими аватарками работает режим `.q bot`.

## purge.py — удаление всех сообщений в группе (включая топики)

⚠️ Удаление необратимо. Без слова `confirm` скрипт только показывает предпросмотр.
Команду лучше вводить в другом чате, например в «Избранном».

| Команда                              | Что делает                                       |
|--------------------------------------|--------------------------------------------------|
| `.purge -1001234567890`              | предпросмотр: сколько сообщений и топиков        |
| `.purge -1001234567890 confirm`      | удалить **все** сообщения (нужны права админа)   |
| `.purge -1001234567890 mine`         | предпросмотр: только мои сообщения               |
| `.purge -1001234567890 mine confirm` | удалить только свои (права не нужны)             |

Чат можно указать как `-100…`, `@username`, ссылку `t.me/…` или `id:123`.

**Удаление до даты.** Добавь дату или срок — удалятся только сообщения
**старше** неё (сама дата не входит, более новые не трогаются). Сначала
предпросмотр, потом то же самое с `confirm`:

```
.purge -1001234567890 90d                  # предпросмотр: старше 90 дней
.purge -1001234567890 до:29.09.2026        # старше 29.09.2026 00:00
.purge -1001234567890 mine 2w confirm      # удалить свои старше 2 недель
```

| Формат                                   | Пример                       |
|------------------------------------------|------------------------------|
| относительно: `h/ч`, `d/д`, `w/н`, `mo/мес`, `y/г` | `12h`, `90d`, `2w`, `6mo`, `1y` |
| дата                                     | `29.09`, `29.09.2026`, `2026-09-29` |
| дата и время                             | `2026-09-29T14:30`           |
| слова                                    | `сегодня`, `вчера`           |

Префикс `before:` / `до:` не обязателен. Предпросмотр показывает точную
границу и количество, а в подсказке команды для удаления дата уже
абсолютная (`before:2026-08-10T22:04`), чтобы удалилось ровно то, что
было в предпросмотре. В форуме с датой топики целиком не удаляются —
только их старые сообщения.

**Сообщения от имени каналов (Premium).** Режим `mine` удаляет и сообщения,
отправленные через «Отправлять как…» от твоих каналов. Список каналов берётся
из меню «Отправлять как» этой группы и показывается в предпросмотре. Если
канала там уже нет, добавь его вручную через `as:`:

```
.purge -1001234567890 mine as:@mychannel as:-1009876543210 confirm
```

В форуме каждый топик удаляется целиком вместе с историей. «Общий» топик
удалить нельзя, его сообщения удаляются по одному. Потом скрипт проходит
по всей оставшейся истории и удаляет сообщения пачками по 100. При FloodWait
он ждёт и продолжает, прогресс пишет в сообщение с командой. Служебные
сообщения (например, «группа создана») Telegram удалить не даёт, их
количество будет в итоговом отчёте.

## dump.py — полный дамп чата

Выгружает историю чата в zip-архив и присылает его файлом в чат, где введена
команда (удобно вводить в «Избранном»). Внутри архива:

- `messages.txt` — читаемая переписка: дата, автор, топик, ответы, подписи медиа;
- `messages.jsonl` — все сообщения целиком в «сыром» виде Telegram (по строке на сообщение);
- `chat.json` — информация о чате, топиках и авторах;
- `media/` — файлы (только с флагом `media`).

| Команда                                      | Что делает                                 |
|----------------------------------------------|--------------------------------------------|
| `.dump -1001234567890`                       | весь чат, без медиа                        |
| `.dump -1001234567890 media`                 | весь чат + все фото/видео/файлы            |
| `.dump @chat 90d`                            | за последние 90 дней                       |
| `.dump @chat 01.09.2026 до:30.09.2026`       | диапазон дат (конец включительно)          |
| `.dump @chat 5000`                           | последние 5000 сообщений                   |
| `.dump`                                      | текущий чат                                |

Чат указывается так же, как в `purge`: `-100…`, `@username`, `t.me/…`, `id:123`
(для лички/бота — только через `id:`). Даты: `12h`, `90d`, `2w`, `6mo`, `1y`,
`29.09`, `29.09.2026`, `2026-09-29`, `вчера`; начало можно писать как `с:…`.

Настройки вверху файла: `DUMP_MEDIA_MAX_MB` — файлы крупнее пропускаются
(по умолчанию 200 МБ), `DUMP_SEND_MAX_MB` — архив больше не отправляется
в Telegram (лимит 2 ГБ), а остаётся на сервере в папке `dumps/` рядом с
модулями TGPy (путь будет в ответе). При FloodWait скрипт ждёт и продолжает.

**Альтернатива без скриптов:** Telegram Desktop → меню чата (⋮) → «Экспорт
истории чата» — выгрузка в HTML/JSON с медиа. Скрипт удобнее, когда TGPy
крутится на сервере, нужен дамп с телефона, по диапазону дат или машиночитаемый
JSON со всеми полями.
